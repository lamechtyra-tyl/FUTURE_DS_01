Business Sales Performance Analytics

Project Overview

This project analyzes business sales data using Microsoft Excel to evaluate revenue, profitability, regional performance, product performance, and monthly sales trends.

Tools Used

- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and timelines
- Interactive dashboards
- Data visualization

Key Performance Indicators (KPIs)

- Total Revenue: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 9,994
- Total Units Sold: 37,873
- Profit Margin: 12.47%

Key Findings

- The West region recorded the highest sales revenue and profit.
- The East region was the second-highest contributor to revenue.
- The South region recorded the lowest sales revenue.
- Technology generated the highest profit among the three product categories shown in the dashboard.
- The interactive analysis allows users to explore regional and time-based performance.

Recommendations

- Investigate the factors contributing to the West region's strong performance.
- Identify opportunities to improve sales and profitability in the South region.
- Monitor monthly sales trends to support better business decisions.
- Use interactive filters to compare performance across regions and time periods.

Project File

- "Business_Sales_Analysis.xlsx" — The Excel workbook containing the analysis and dashboard.

Conclusion

This project demonstrates how Microsoft Excel can transform raw sales data into useful business insights through data analysis, interactive filtering, and dashboard visualization.
